# 技能投影与锁定

Registry 与锁文件各持有自己的事实：active Registry 管技能身份、别名、能力、依赖与发现面；skills-lock.json 管来源、上游/有效目录摘要与投影完整性，不互相替代。

共享技能只改 canonical `.agents/skills`，再生成投影并更新锁；平台专属内容按其所属 root 维护。

平台专属技能保留在其平台 root 并由 platform 分组记录。投影可以是正确目标的符号链接或完整同步副本，使用现有 sync-skills/update-skill-lock 入口验证；不能分别手改投影或将偶然出现的未登记目录自动纳入分发。

技能名派生摘录只表达当前名称，不包含来源 hash 和路径，也不证明 Skill 当前会话已读取。公开分发按当前清单与发布合同处理；llm-wiki 与通用流程技能不因本地可发现获得公开发布权限。参见 [[模板维护流程]]、[[YSS路由与合同编译]]。
